# Pahado Ki Duniya - Connected Version

A responsive hotel/homestay discovery website for Mussoorie, Dehradun and Rishikesh, connected to Supabase.

## Files
- `index.html` - website UI
- `style.css` - responsive styling
- `script.js` - Supabase data, bookings and admin logic
- `config.js` - Supabase URL + publishable key
- `supabase/schema.sql` - database and RLS setup
- `SETUP.md` - exact setup instructions

## Important
The browser uses only the Supabase publishable key. Never put a Supabase secret/service-role key in this project.
